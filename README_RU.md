# Golden Fox Sports Academy — Prototype V1

Дизайн-прототип многостраничного сайта по итогам 10 этапов технического задания.

## Как открыть

1. Распакуй ZIP.
2. Открой `index.html` в браузере. Для наиболее корректной работы можно запустить `python -m http.server 8000` внутри папки и открыть `http://localhost:8000`.
3. Попробуй навигацию, переключение DE/EN/UA/RU, фильтры Trainings, интерактивные уровни Academy и мобильное меню.

## GitHub Pages

Загрузи **содержимое папки** (файлы `index.html`, `trainings.html` и т.д. плюс папки `assets/`, `css/`, `js/`) в корень репозитория. В Settings → Pages выбери Deploy from a branch, main / (root). Ссылка будет вида `https://имя.github.io/репозиторий/`.

Можно создать отдельный репозиторий `goldenfox-prototype`, чтобы **не перезаписывать действующий сайт**. Публичную ссылку на тестовый прототип не стоит выдавать клиентам как полноценный действующий сайт.

## Что работает в прототипе

- 10 отдельных HTML-страниц, единая навигация и футер.
- Отзывчивая мобильная версия и мобильное меню.
- Переключение между немецким, английским, украинским и русским (основные UI-тексты; отдельные вторичные тексты ещё требуют перевода).
- Интерактивный подбор демонстрационных программ по городу, аудитории, спорту и уровню.
- Интерактивная система пяти уровней, анимации появления и линии прогресса.
- Демонстрационная контактная форма (ничего не отправляет).
- Настоящий неизменённый логотип из предыдущих материалов.
- Места под **твои** реальные фотографии без искусственных фотографий клиентов.

## Что пока не работает

**Нет:** действующих расписаний, актуальных свободных мест, реальных бронирований, личных кабинетов, обработки платежей, сервера, базы данных, отправки email, онлайн-заказов. Карточки курсов — только варианты интерфейса и не являются обещанием услуги.

## Следующий этап

Согласовать внешний вид, передать реальные фотографии (и если потребуется исходный логотип в более высоком разрешении), затем окончательно написать публичные тексты, проверить переводы. После этого реализовывать сервер, авторизацию, бронирование и юридическую подготовку к коммерческому запуску.
