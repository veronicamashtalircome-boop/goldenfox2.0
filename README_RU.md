# Golden Fox — исправленная версия для GitHub Pages

Это версия **с плоской структурой файлов**: все HTML, CSS, JS и логотип лежат в корне.

## Обновление
1. Открой GitHub → репозиторий goldenfox2.0 → Code.
2. Нажми Add file → Upload files.
3. Распакуй ZIP на компьютере. Загрузи **все файлы из распакованной папки** (не ZIP и не саму папку): index.html, app.js, style.css, golden-fox-logo.png, другие HTML и README_RU.md.
4. Убедись, что файлы лежат рядом в корне репозитория (должны отображаться как `style.css`, `app.js`, `golden-fox-logo.png`).
5. Commit changes. Через некоторое время обнови опубликованный сайт с Ctrl+Shift+R.

Если GitHub предлагает заменить файлы с одинаковыми именами, подтверди замену. Старые папки css, js и assets можно оставить, они не используются в исправленной версии.

Это прототип без коммерческой регистрации и оплаты.
